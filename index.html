TRAE IDE 功能變更對照表

欄位：版本 / 原況 / 變更 / 影響 ｜ 依官方更新日誌（2026 年 01 月 – 10 月）整理，由新到舊排列

資料來源：TRAE 官方 Changelog

版本 發布日 功能 原況 變更 影響
v3.6.0 2026/10/08 新功能
Agent 視窗		 TRAE 是一個 IDE，所有事情都在編輯器視窗內完成，且以「單一專案」為中心。 新增以 Agent 為中心的全域工作區。可在同一視窗指揮跨多個專案的多個 Agent，支援雲端任務與排程任務，集中管理產出物（程式碼、文件、簡報、圖片、影片）。可與 IDE 視窗自由切換，資料自動同步。 從「開專案寫程式」變成「開視窗管任務」，適合同時處理多條工作線（如制度文件＋衛教內容）。
v3.6.0 2026/10/08 新功能
遠端主機目錄（SSH）		 主要操作本機目錄，遠端檔案需先拉回本機或走既有遠端流程。 可從 Agent 視窗直接連線遠端主機上的目錄，將該目錄作為工作目錄，並在遠端環境執行任務。 程式碼放在伺服器時，不需先同步到本機即可直接作業。
v3.6.0 2026/10/08 新功能
單專案掛多路徑		 一個專案對應一個資料夾，跨倉庫需切換視窗。 支援在單一專案掛載多個路徑。任務仍以「專案」為單位組織，但檔案樹與全域搜尋可跨專案運作。 多倉庫（multi-repo）開發更順，減少視窗切換成本。
v3.6.0 2026/10/08 新功能
桌面伴侶機器人		 必須開啟主視窗才能派任務、查看進度。 新增常駐桌面的小機器人，不開主視窗也能啟動任務、追蹤 Agent 進度。 提供隨手可用的任務入口，降低切換成本。
v3.5.97~104 2026/09/20 新功能
外掛市集		 外掛取得管道零散，需自行搜尋來源。 推出官方 Marketplace，提供開發工具、生產力、內容創作等多用途的專門外掛。 需要特定能力時，可在市集內一次找到並安裝。
v3.5.93~96 2026/09/01 優化
關鍵字搜尋		 查詢方式較受限。 支援以關鍵字搜尋查詢內容。 查找歷史／內容更精準。
v3.5.84~92 2026/08/20 新功能
連接 TRAE Mobile		 任務與進度只能在桌面端掌握。 支援將 TRAE 連接行動版；可在電腦發起任務，於手機追蹤進度或補充指令。 離開電腦也能掌握任務，行動辦公更便利。
v3.5.84~92 2026/08/20 新功能
Max 模式		 模型能力為固定檔位。 特定模型可開啟 Max 模式，取得更強的推理表現。 遇到困難任務時可切到 Max 換取更佳結果（通常也更耗資源）。
v3.5.84~92 2026/08/20 優化
對話流縮圖導覽		 長對話需手動往上滑找特定訊息。 對話面板左側新增縮圖導覽，可一鍵跳到任一則提問。 長對話瀏覽效率明顯提升。
v3.5.74 2026/07/08 新功能
瀏覽器設定面板		 瀏覽器相關設定分散。 設定中心新增集中式瀏覽器設定面板（個人版）；Windows 版整合 MSSDK。 Browser Use 相關設定集中管理，調整更方便。
v3.5.69~70 2026/06/23 優化
內建 Agent 整併		 內建多組 agent，選項較複雜。 整併內建 agent，只保留「Chat」與「Agent」兩個；同時修正 Write 工具在串流模式下編輯既有檔案的 Diff 問題。 入口更單純，減少選錯 agent 的困擾。
v3.5.67 2026/06/17 新功能
TRAE Enterprise		 以個人／團隊使用為主。 推出企業版；支援從 .trae/agents 目錄載入 subagent 定義檔（需在 Beta 設定開啟「Enable Subagents Directory」）；對 -1、3003 等可重試錯誤自動重試並撤回未執行的工具卡。 企業可集中管理；subagent 可自訂；錯誤處理更自動化。
v3.5.66 2026/06/10 新功能
Hooks		 Agent 行為難以「保證」在某些時點執行特定動作。 支援 Hooks：使用者自訂的 shell 指令，在 TRAE 生命週期特定階段自動執行，提供對 Agent 行為的確定性控制。另逐步取消 Agent Delete 工具的自動執行，刪除的檔案可在系統回收桶找到。 用規則強制某些動作一定被執行；誤刪風險降低。
v3.5.58 2026/05/15 新功能
影片理解		 Kimi K2.5 / K2.6 僅支援文字。 Kimi K2.5 / K2.6 模型支援影片理解。 可直接丟影片讓模型理解內容。
v3.5.56 2026/05/08 優化
Agent 整併與改名		 Builder 與 Builder with MCP 並存；SOLO Coder 命名。 Builder 與 Builder with MCP 併入 Agent；SOLO Coder 改名 SOLO Agent。專案指令檔 .trae/commands/ 支援最多三層巢狀目錄。 命名與入口簡化；指令檔可依目錄分層管理。
v3.5.54 2026/04/28 新功能
Slash 指令		 常用指示需每次重打。 支援自訂 Slash 指令，把常用指示或動作封裝成指令；設定面板重新歸類為 Index & Docs、Skills & Commands、Rules。 重複性工作可一鍵套用；設定項目更好找。
v3.5.51 2026/04/14 新功能
Rules 強化		 規則僅能以單層方式管理，缺乏模組化與 Git 訊息規範。
  • 支援規則巢狀：.trae/rules/ 可建子資料夾，系統遞迴讀取最多 3 層。
  • 支援子目錄規則：專案任一子目錄可建 .trae/rules/，套用於該模組。
  • 原始碼控制面板新增「設定 Commit Message 生成規則」入口。
  • MCP 支援完整 OAuth（授權／執行／呼叫／撤銷）。
  • 自訂模型可設定自訂請求 URL。
 規則可依模組分層治理；Git 提交訊息可統一風格；MCP 授權流程完整；可接自架模型端點。
v3.5.47 2026/04/09 優化
自動開啟終端		 Agent 執行終端命令時，終端不會自動顯示。 對話流設定新增「執行命令時自動打開終端」選項，開啟後執行命令時自動顯示對應終端。 可即時看到命令執行狀況，便於除錯。
v3.5.44 2026/04/02 新功能
Skills 目錄 / Commit 規則		 Skills 載入位置固定；Git commit 訊息無法規範。 支援從 .agents/skills 目錄載入技能；支援設定 AI 生成 Git commit 訊息的規則。 技能可放在通用目錄被工具共用；提交訊息符合團隊規範。
v3.5.39~41 2026/03/21 優化
終端機唯讀重構		 Agent 終端執行效能與穩定性不足，長時任務管理不易。 終端執行重構為唯讀架構（逐步推出），效能與穩定性提升；新增終端命令卡片與背景任務塢，管理長時間命令；修正大量終端卡片造成的閃爍。
（如遇問題可於 設定 > 對話 > 終端機偏好 還原。）		 長時間任務更好管理，畫面更穩定。此版同時新增資源管理器的 CPU／記憶體 AI 診斷。
v3.5.35 / v3.5.37 2026/03/05 新功能
Markdown 預覽		 Markdown 只能看原始碼。 編輯器可直接預覽 Markdown，並在「Preview／Markdown」間切換，可於一般設定指定預設顯示模式；SOLO 模式開啟 Markdown 預設為即時可編輯預覽。 寫文件所見即所得，適合報告與衛教稿撰寫。
v3.5.31 2026/02/12 新功能
SOLO Spec 模式		 SOLO Coder 以 Plan 模式切換。 新增 Spec 模式；移除 Plan 模式切換鈕，改用 /plan 與 /spec 指令切換模式；終端體驗優化。 規格化開發流程更完整，模式切換更直覺。
v3.5.26 2026/01/30 優化
對話流操作		 任務執行中無法即時管理當前訊息。 任務執行期間可複製、刪除、回退當前訊息；終端命令執行體驗優化。 修正方向不必重開對話，節省時間。
v3.5.24~25 2026/01/23 新功能
Skills 強化		 Skills 僅能在特定範圍使用。
  • 支援全域與專案技能，可手動啟停，可在 IDE 模式與自訂 agent 使用。
  • 支援專案層級 MCP。
  • AI 在終端執行的命令不再寫入終端歷史。
  • AI 對話流可渲染 LaTeX 公式。
  • macOS 版新增狀態列；歡迎頁與設定支援 IntelliJ 快捷鍵。
 技能可跨專案重用且可自由控管；MCP 可跟專案走；公式顯示正常。
v3.5.21 2026/01/13 新功能
Skills 建立與 SOLO 使用		 建立技能的方式有限。 支援手動上傳並新增技能，且可在 SOLO 模式中使用。 可把自己慣用的流程封裝成技能，反覆套用。
